# fomo-desk (web)

Static app published by GitHub Pages. It holds no data and no keys.
Open it once with `https://se489397-ux.github.io/fomo-desk/#d=<data id>`; the id is kept in the
phone's localStorage. The desk process on the owner's box writes the data elsewhere.
PAPER mode: no orders are placed and no funds are touched. Every FOMO link carries r=savipww.
